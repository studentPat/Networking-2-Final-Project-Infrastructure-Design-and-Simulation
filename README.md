# Networking 2 Final Project: Infrastructure Design and Simulation

This repository contains a Cisco Packet Tracer network-infrastructure design and its supporting project documentation. The project demonstrates the planning and simulation of a network environment as part of a Networking 2 final project.

The repository is intended for networking students, instructors, recruiters, and collaborators who want to review a practical infrastructure-design deliverable without needing to inspect source code.

## What is included

- **Cisco Packet Tracer simulation** — [`cisco-simulation.pkt`](cisco-simulation.pkt)
- **Project documentation** — [`final-project-documentation-networking.pdf`](final-project-documentation-networking.pdf)

The `.pkt` file is the interactive deliverable. The PDF provides the written project documentation and should be read alongside the simulation.

## Project focus

The project addresses the design and validation of a simulated computer-network infrastructure. Cisco Packet Tracer provides a safe environment for modeling network devices, connections, and configurations before deployment on physical equipment.

Because this repository contains a simulation artifact rather than an application, there are no application APIs, database migrations, dependency manifests, or automated test commands to run.

## How to review the project

### Prerequisites

Install Cisco Packet Tracer on a supported desktop environment. The required Packet Tracer version is not recorded in this repository; use a version compatible with the supplied `.pkt` file.

### Open the simulation

1. Clone or download this repository.
2. Open `cisco-simulation.pkt` with Cisco Packet Tracer.
3. Review the topology in the logical or physical workspace.
4. Inspect the device configurations and use Packet Tracer simulation tools to examine network behavior.
5. Read [`final-project-documentation-networking.pdf`](final-project-documentation-networking.pdf) for the accompanying design documentation.

No package installation, environment variables, server process, or database setup is required.

## Validation and testing

There is no automated test suite in the repository. Validation is performed interactively in Cisco Packet Tracer by opening the simulation, reviewing device configurations, and observing the modeled network behavior.

## Current status and limitations

- The repository is a completed project submission consisting of a Packet Tracer simulation and written documentation.
- The project is not a deployable production network or standalone software application.
- The exact device inventory, addressing plan, configuration commands, and verification results are documented in the PDF and the Packet Tracer file rather than represented as text source files.
- The repository does not include screenshots, a separate topology image, a required Packet Tracer version, or a software license.
